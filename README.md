# MathFFM
Math marshalling & unmarshalling library using java `MemorySegment` and the types from [this api](https://github.com/Lidiuma/MathAPI).

# How to Use
**Gradle**
```groovy
implementation("org.lidiuma.math:math-ffm:0.1.0-SNAPSHOT")
```
**Bld**
```java
include("org.lidiuma.math", "math-ffm", snapshot(0,1,0))
```
